# 对话记录与跨设备恢复

此目录保存可读对话摘录和协作摘要，`../context.md` 保存最新项目状态，根目录 `AGENTS.md` 指引新对话读取和维护它们。

## 在另一台设备继续

1. 在当前设备将代码、`AGENTS.md` 和 `docs/` 一起提交并推送到 GitHub。
2. 在另一台设备克隆或拉取仓库，使用 Python 3.10 或更高版本。
3. 在项目根目录打开 Codex，新建对话并输入：

   > 请先阅读 AGENTS.md 和 docs/context.md，了解当前进度；按需查看 docs/conversations/，然后继续我的项目任务。

新对话可从这些文件恢复需求、决定和进度；这些文件不是原始会话数据库，也不恢复旧线程的界面状态。

## 后续如何保存

按根目录 `AGENTS.md`，在有实质进展的工作结束前更新上下文并追加当天的协作摘要。默认保存摘要，无后台逐条同步；需要逐字对话时，须从实际可访问的消息中导出并注明截止范围。

提交前查看新增内容是否适合仓库的可见范围。不要将整个本机 Codex 数据目录作为对话记录提交。
