## 目标与用户决定

项目实现以预定义事件为中心的 Python 基础库：人物携带实际经历，调用者选择当前允许发生的事件，事件读取相关历史结果并为多个参与者追加共同事件的结果。

## 当前实现

- 包名 `eventgraph-world`，版本 `0.1.0`，要求 Python 3.10+，无第三方运行依赖。
- `eventgraph/models.py` 定义事件、结果、连接、角色、时间窗口和追加式经历。
- `eventgraph/flows.py` 提供 `Flow` 与组合查表 `TableFlow`，支持完整覆盖、默认分支和显式输入域。
- `eventgraph/graph.py` 提供图校验、派生 schema、可触发性检查、执行、事务式 `append` 和 `replace_result`。
- `eventgraph/document.py` 提供 version 1 JSON 导入导出，支持表格流程和未配置流程的节点定义。
- `eventgraph/ordering.py` 合并必需触发依赖与严格分离窗口的时间约束，使用紧凑结构进行无环检查及分层。
- `eventgraph/layout.py` 提供关系分析和确定性三维布局，支持最小中心间距、邻居吸引和复用旧位置的稳定更新。
- `python3 -m eventgraph` 可将事件 JSON 导出为规范化定义与布局 JSON；`examples/events.json` 为八节点样例。用法见 [JSON 解析与三维布局](json-layout.md)。
- `examples/school_world.py` 演示入学、考试、工作经历、求职及结果替换。
- `eventgraph/viewer.py` 提供离线本地查看器，`eventgraph/web/` 用原生 Canvas 绘制三维投影；支持相机操作、节点详情、JSON 导入和布局导出。28 节点样例为 `examples/branching.json`，用法见 [三维查看器](viewer.md)。
- Python 共 59 项测试，另有可选的 `tests/test_renderer.mjs` 几何检查。接口与详细设计见 [API 说明](api.md) 和 [设计说明](design.md)。

## 需要保留的设计决定

1. 图表达结果依赖，不规定人物必须沿固定路径行动；事件定义与实际执行记录分离。
2. 触发条件是全部满足的必需历史结果，相关项是可选流程输入；两类输入不相交，schema 从图中派生。
3. 一次执行产生一个联合输出，按角色写入个人经历或世界级结果；没有发生的事件不生成占位记录。
4. 改变已有事件的输入或输出必须显式提供 `flow_updates`；校验失败不提交图更新。
5. 替换结果保留历史快照，旧 ID 退休且不可复用；旧经历不会自动映射到新结果。
6. 历史按世界时间非递减追加；未来结果不能作为过去执行的输入。
7. 必需触发依赖及严格分离窗口产生的先后关系必须共同无环；双向相关项合法，不参与强制排序。
8. JSON 是后续 App 的事件数据来源；布局为派生快照，Y 表示层级而非实际时间，不能根据高度差虚构业务依赖。

这些决定依据现有代码说明整理，更早的原始开发对话没有归档到本项目。

设计约束：`TimeWindow` 是允许触发的窗口，不是持续时间；窗口可交叉。用户禁止互为必需前提的因果关系，但允许 A 先发生后影响 B，或 B 先发生后影响 A。必须区分必需前提与可选影响：相关项可以双向连接，不形成固定顺序；具体执行只读取此前实际存在的结果。不能对包含所有连接的整张图一概禁止环。底层现已在图事务提交前检查强制排序约束，失败时保留原图。

最新设计方向：三维树形布局表达必需前提及时间产生的先后约束，不把主干作为数值时间轴；事件用单个节点表示。当前布局在各层的 XZ 平面用六角网格保证中心间距，以邻居加权中心引导有限轮调整；保留全部业务连接，不把隐含时间顺序展开成密集连线。传入旧布局可稳定更新位置，约束变化时仍需调整高度或解决位置冲突。渲染已有沿真实因果路径加粗的连续主干、装饰树基、渐细枝桠、三维表面粒子和纤维；关联项是虚幻粒子弧，不参与主干计算。查看器节点间距调整为 5.0 展开树冠，库默认间距保持 3.0。保留透视相机、标签避让与关联聚焦。节点较密时仍可能投影重叠，可旋转或从目录选取；当前启发式布局不保证全局最优。
