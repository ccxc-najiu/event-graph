## 当前实现

- 包名 `eventgraph-world`，版本 `0.1.0`，要求 Python 3.10+，无第三方运行依赖。
- `eventgraph/models.py` 定义事件、结果、连接、角色、时间窗口和追加式经历；`Event.content: object` 替代原 `flow`，`FlowEvent` 保留流程执行。`eventgraph/content.py` 定义统一内容描述约定及 `NodeContent`。
- `eventgraph/flows.py` 提供 `Flow` 与组合查表 `TableFlow`，支持完整覆盖、默认分支和显式输入域。
- `eventgraph/graph.py` 提供图校验、派生 schema、可触发性检查、执行、事务式 `append` 和 `replace_result`。
- `eventgraph/document.py` 导出 version 2 JSON，兼容导入 version 1；支持带描述的通用节点内容、表格流程和未配置流程。
- `eventgraph/ordering.py` 合并必需触发依赖与严格分离窗口的时间约束，使用紧凑结构进行无环检查及分层。
- `eventgraph/layout.py` 提供关系分析和确定性三维布局，支持最小中心间距、邻居吸引和复用旧位置的稳定更新。
- `python3 -m eventgraph` 可将事件 JSON 导出为规范化定义与布局 JSON；`examples/events.json` 为八节点样例。用法见 [JSON 解析与三维布局](json-layout.md)。
- `examples/school_world.py` 演示入学、考试、工作经历、求职及结果替换。
- `eventgraph/viewer.py` 提供离线本地查看器，`eventgraph/web/` 用原生 Canvas 绘制三维投影；支持简约/拟态切换、相机操作、节点详情、JSON 导入和布局导出。28 节点样例为 `examples/branching.json`，用法见 [三维查看器](viewer.md)。
- Python 共 73 项测试，另有可选的 `tests/test_renderer.mjs` 几何检查。接口与详细设计见 [API 说明](api.md) 和 [设计说明](design.md)。

## 需要保留的设计决定

1. 图表达结果依赖，不规定人物必须沿固定路径行动；事件定义与实际执行记录分离。
2. 触发条件是全部满足的必需历史结果，相关项是可选流程输入；两类输入不相交，schema 从图中派生。
3. 一次执行产生一个联合输出，按角色写入个人经历或世界级结果；没有发生的事件不生成占位记录。
4. 改变已有事件的输入或输出必须显式提供 `content_updates`（旧 `flow_updates` 保留为兼容别名）；校验失败不提交图更新。
5. 替换结果保留历史快照，旧 ID 退休且不可复用；旧经历不会自动映射到新结果。
6. 历史按世界时间非递减追加；未来结果不能作为过去执行的输入。
7. 必需触发依赖及严格分离窗口产生的先后关系必须共同无环；双向相关项合法，不参与强制排序。
8. JSON 是后续 App 的事件数据来源；布局为派生快照。2026-10-11 用户在花朵尝试后要求恢复树布局，保留笔直树干：无触发前置的事件从主干延伸，其余从触发节点延伸，多个前置保留全部连接。用户随后要求触发枝更粗凝实、关联枝更细虚幻；关联不决定分枝归属。节点 Y 仍表示先后层级；树干和根支撑不产生业务依赖。

这些决定依据现有代码说明整理，更早的原始开发对话没有归档到本项目。
