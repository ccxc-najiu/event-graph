# 三维事件查看器

在项目根目录运行（Python 3.10+，无需安装前端依赖）：

```bash
python3 -m eventgraph.viewer examples/branching.json --port 8765
```

浏览器打开 `http://127.0.0.1:8765`，终端 Ctrl+C 停止。将文件参数替换为自己的 version 1 事件 JSON。格式见 [JSON 解析与布局](json-layout.md)。服务仅监听本机，浏览器资源均随包提供，可离线使用。

## 画面与语义

配色参考用户提供的 [电蓝树形线束](concepts/electric-blue-reference.png)：近黑底色、粗壮电蓝枝桠、青色节点、表面粒子与少量辉光。原生 Canvas 将布局 XYZ 坐标透视投影到屏幕；旋转改变相机，不改变数据或先后约束。

事件是单个节点，高度表示先后层级。时间窗口仍是允许发生的区间，显示在节点详情中，不转成持续时间或数值高度。触发连接绘制为逐渐变细的枝桠：沿真实触发依赖选择后续分叉较多的路径作为粗主干，相关项完全不参与主干和粗细计算。根部延伸一段装饰树基，不代表新的事件或依赖。多个独立因果根保留为多棵树，不强行互连。相关项绘制为抬起的稀疏、半透明粒子弧，不绘制实体管体；双向关系保留，选择节点后显示方向箭头。枝干表面的螺旋纤维和粒子都在三维坐标中采样，随相机转动，装饰不增加业务关系。结果定义和各条连接的来源在详情中列出，不再铺开额外结果节点。仅有时间先后关系时不虚构连线或树干。

相关项默认收起，选中事件后显示它的直接关联并淡化其他节点。名称会避让，窄屏减少同屏标签；隐藏标签不删除节点，可从列表搜索和选取。示例包含 28 个节点、30 条触发连接、6 条相关连接和 5 层。

## 操作

- 拖动旋转；Shift 拖动或右键拖动平移；滚轮或双指捏合缩放。
- 点击节点或左侧目录查看时间窗口、角色、结果及输入/输出连接；点击详情中的关联项跳转选择。
- “环绕”开启或暂停自动旋转，“正视”与“复位”重置相机，减号/加号缩放。
- 画布获得键盘焦点后，方向键旋转，`+` / `-` 缩放，Home 复位，Escape 取消选择。
- 搜索按事件名称或 ID 筛选目录；名称、辉光和相关项显示可以独立切换。

## 导入与导出

“导入 JSON”支持选文件或粘贴。原始事件 JSON 经底层解析、校验与布局成功后替换当前图；失败保留原图。也可重新导入查看器导出的 `{graph, layout}` 文件，其中 `graph` 重新校验并布局，旧坐标不作为事实来源。

“导出布局”下载 `.scene.json`，包含当前规范化 `graph` 与 `layout`。导入数据只保存在当前浏览器页面内，刷新恢复启动时的文件内容；服务不写回原文件、不修改其他窗口。当前尚无可视化节点编辑、自动保存或执行历史展示。

## 结构与边界

- `eventgraph/viewer.py`：静态资源、本地场景读取与解析布局 API。
- `eventgraph/web/app.js`：界面、选择状态、导入与导出。
- `eventgraph/web/renderer.js`：相机投影、曲线、节点、标签及指针操作。
- `eventgraph/web/styles.css`：桌面三栏与窄屏布局。

每次导入最多 2 MiB、3,000 个事件、12,000 条连接；这是输入保护范围，不是流畅帧率保证。查看器使用 5.0 的节点间距展开树冠，底层布局接口默认值仍为 3.0。超过 150 个事件时减少装饰线束，并按连接总量限制粒子采样预算，静止时按需绘制，自动旋转默认关闭。密集数据仍可能在某些相机角度重叠，后续可针对真实数据继续改进布局和筛选。

测试：`python3 -m unittest discover -s tests -v`。可选的几何检查需要 Node.js：`node tests/test_renderer.mjs`，不需要 npm 包。已人工验证桌面、窄屏、节点详情、缩放、非法导入恢复、合法双向相关项导入与 JSON 下载。最新树形版本另验证旋转、关联显示和节点聚焦；几何测试覆盖主干只沿真实因果边、相关项不影响主干、无因果边时不生成树基、粒子确定性与有限坐标。
