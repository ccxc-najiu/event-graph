# 三维事件 App 基本要求

确认日期：2026-10-10；视觉方向更新：2026-10-11。用户随后授权先实现第 1、2 项，并提供黑底电蓝树形线束参考图。现已完成解析、布局与简化三维渲染，第 4 项可视化节点编辑待实现。接口与实现边界见 [JSON 解析与三维布局](json-layout.md)。

## 四项核心能力

1. **解析原始事件 JSON**：读取事件节点、结果及连接，得到各节点的因果依赖、可选影响和时间先后约束。已实现 version 1 的事件、结果、连接格式。
2. **排位布局**：在满足先后约束的前提下，为节点安排合适的三维位置，追求美观、简洁、优雅，减少遮挡和连线杂乱。无先后约束的节点按布局需要自由放置，方便添加新节点。
3. **渲染**：依据布局结果绘制事件节点、结果端口和连接。事件以单个节点表示。最新要求恢复树布局并保留笔直主干：没有触发前置的事件从主干延伸，其余事件从自身触发节点延伸；触发枝加粗凝实、关联枝更细虚幻，节点高度表示先后层级。
4. **可视化编辑节点**：支持以可视化方式新增、修改事件节点。代码逻辑先修改 JSON 数据，再更新关系解析、排位布局和渲染；不能只修改画面而不更新数据。

## 数据流与模块边界

JSON 是事件数据的事实来源；关系、位置和画面由它派生。

```text
事件 JSON → 解析与底层校验 → 关系及先后约束 → 排位布局 → 渲染
    ↑                                                        │
    └──────────────── 可视化编辑 ────────────────────────────┘
```

解析、布局、渲染、编辑各自职责清楚。渲染不重新解释事件因果关系；布局不修改业务语义；编辑通过更新 JSON 驱动后续变化。解析与布局基于 Python 标准库，已提供独立接口和命令行 JSON 输出；渲染采用原生 JavaScript 与 Canvas 三维投影，本地 Python 服务复用解析和布局；编辑器及持久化方式待确定。

## 关系语义

- `TimeWindow` 表示允许事件发生的时间窗口，不是事件持续时间。
- A 的结果是 B 的必需触发条件时，形成 A 在 B 之前的依赖。
- A 的窗口结束严格早于 B 的窗口开始时，若两者均发生，则 A 在 B 之前。端点相等不据此推导严格先后；无界端点不能擅自当作有限时间。
- 窗口交叉本身不产生固定顺序；没有强制顺序的事件不必按时间数值排列。
- A、B 不能互为必需前提；这类合法性由底层检查，可视化不负责修补非法因果关系。基础库现已在事务提交前检查必需依赖和时间顺序合并后的环。
- A 先发生影响 B，或 B 先发生影响 A，均可成立。双向可选影响必须保留，不作为强制排序约束，不能对包含相关项的整张图一概禁止环。
- 布局支持分叉与多个前置事件汇合，不要求业务数据成为单父节点的纯树。精简显示不能删除真实依赖。

## 质量要求

代码应简洁、优雅、高效，采用清楚的数据流和必要的抽象，避免重复状态与无必要的复杂设计。效率要求覆盖解析、布局、渲染和编辑更新的完整过程；节点规模及具体性能指标待后续确定。

视觉优先级是美观、简洁、优雅、避免杂乱，并保持三维空间表现力和新增节点的便利性。2026-10-11 用户在花朵尝试后要求恢复树布局并保留主干。已移除花瓣和环形排位，恢复服务端通用约束布局；无触发前置的事件接入笔直主干，有触发前置的事件沿真实触发连接分枝，多前置事件保留全部连接。主干及根节点支撑枝是视觉结构，不新增业务依赖。

用户随后要求触发枝更粗、更凝实，关联枝更细、更虚幻。已实现蓝色实体枝身与高光，以及淡紫色细底线叠加稀疏光点；关联项默认显示。选择后保留直接关联并显示业务连接方向，标签自动避让。库布局支持传入上次位置实现稳定更新；查看器导入目前仍根据定义重新布局。详见 [三维查看器](viewer.md)。

## 双形态显示（2026-10-11）

用户将当前外观命名为“简约形态”，要求新增参考图风格的、更像树的“拟态”，两者可切换。现已实现画布右上方双按钮切换：简约保持电蓝实枝与虚枝；拟态新增电蓝发光树冠、渐细枝条、树干纹理和外扩根部。切换只影响绘制，事件坐标、连接、选择及相机保持不变；拟态小枝是装饰，不新增业务关系。参考图与两种预览见 [三维查看器](viewer.md)。

## 树冠展开与关联藤蔓（2026-10-11）

用户要求树冠向四周展开，节点不要挤在主干附近，并将过于虚幻的相关连接改得更凝实、像藤蔓。已在查看器服务端按触发分枝方位展开节点、为主干留空，保留层级和全部连接；两种形态共用新布局。关联线改为更清晰的青蓝实体曲线，带自然下垂与轻微弯绕。原有“关联更虚幻”的外观要求被本轮藤蔓方向替代。
